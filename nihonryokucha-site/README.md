# 日本緑茶株式会社 コーポレートサイト（リニューアル案）

近江茶の加工メーカーとしての技術と、自社ブランド「彩 AYA PASTE」を打ち出すコーポレートサイト（BtoB）です。
ECサイトは別ドメイン（`nihonryokucha.shop` 予定）で立ち上げるため、本サイトではメニューとバナーからのリンクのみ設計しています。

## 確認方法

静的HTMLのみで動きます。フォルダで簡易サーバーを起動してブラウザで開いてください。

```bash
cd nihonryokucha-site
python3 -m http.server 8000
# → http://localhost:8000/
```

## デザインの考え方

- 「彩」チラシの世界観をそのままWebへ：墨緑（ヒーロー・データ帯）と和紙色（本文）の帯を交互に重ね、金の細線・金のグラデーションでアクセント。
- 書体：見出し＝Shippori Mincho B1、本文＝Zen Kaku Gothic New、欧文＝Cormorant Garamond、筆記体＝Pinyon Script（Google Fonts）。
- 彩ロゴはチラシPDFのベクターデータから透過PNGで書き出し（白版・緑版、マーク単体・ロックアップ）。社名ロゴは `.ai` から書き出し（緑版・白版）。
